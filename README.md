⚠️ Nefret Söylemi Tespiti (Hate Speech Detection)
📌 Proje Açıklaması

Bu projede, metin verileri üzerinde nefret söylemini tespit etmek amacıyla doğal dil işleme (NLP) teknikleri kullanılmıştır.
Amaç, sosyal medya ve kullanıcı içeriklerinde zararlı dili otomatik olarak sınıflandırabilen bir model geliştirmektir.


🤖 Kullanılan Modeller
Logistic Regression
Naive Bayes
Support Vector Machine (SVM)
(Opsiyonel) LSTM / Deep Learning


🛠️ Kullanılan Teknolojiler
Python
Pandas
NumPy
Scikit-learn
NLTK / SpaCy
Matplotlib / Seaborn
